# Hangman Game

## Description

A simple text-based Hangman game developed using Python.

The player has to guess a randomly selected word one letter at a time.

## Features

- Random word selection
- Five predefined words
- Letter-by-letter guessing
- Maximum 6 wrong guesses
- Console-based gameplay

## Technologies Used

- Python
- Random module
- While loop
- If-else statements
- Lists
- Strings

## How to Run

Run the following command:

python hangman.py# Hangman-Game-Python
